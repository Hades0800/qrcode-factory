# 裁切加工計畫表（現場主畫面）

依 `加工MES_資料表設計.jpg`（2026-10）。這是現場看的那一張表：**選機台 + 選日期**，
列出當天要做的加工單，依生產順序排。

```
2026.10月份裁切加工計畫表      機台編號: (31) 32 33      加工日期: 2026.10.01
```

## 欄位

| # | 欄位 | 資料來源 | 存在哪 |
|---|------|----------|--------|
| 1 | 生產順序 | 生管排單 | `ProcessOrder.seqNo` |
| 2 | 客戶名稱 | ERP | `customer` |
| 3 | 製造單號碼 | ERP；沒有對應製造單時顯示 `------` | `manuOrderNo` |
| 4 | 加工單號碼 | ERP | `processNo` |
| 5 | **領料與生產規格**〔按鈕〕 | 點「開啟」跳出該單的 QRP 內容 | `items` / `materials` |
| 6 | **加工配置圖**〔按鈕〕 | 點「開啟」跳出 SKCutTool 的裁切配置圖 | `layoutFile` |
| 7 | 交貨日期 | 業務助理 | `dueDate` |
| 8 | 等待材料 | ERP / 現場 | `waitingMaterial` |
| 9 | **開始時間**〔點選〕 | 現場點一下記錄 | `startedAt` |
| 10 | **完成時間**〔點選〕 | 現場點一下記錄 | `finishedAt` |
| 11 | 作業總人數 | 現場 | `totalWorkers` |
| 12 | 入庫儲位 | 現場 | `storageLocation` |

〔按鈕〕= 點開看文件　〔點選〕= 點一下寫入當下時間

## 兩個彈出內容

**領料與生產規格** —— 就是 QRP 的內容，依這張單的來源顯示製造單或加工單：
- 製造單：工令單號、客戶、產品型號、訂單品名規格 / 訂單數 / 領用材料 / 數量 / 重量、
  生產品名規格 / 派工數 / 刀數 / 製造規格 / 產品寬長
- 加工單：工令單號、領用材料、裁剪加工品名規格 / 數量、零星裁剪、待料中、備料人員、
  寬度 / 長度 / 對角線公差、裁剪方式、包裝方式、操作機台、操作員、開始 / 完成時間

**加工配置圖** —— SKCutTool 的輸出：版型 / 板號 / 片數 / 板材尺寸 / 板厚 表格、
配置圖（紅線裁切圖、刀序）、裁切件統計。

## 單號關係（這張圖確認的）

```
工令 E1150929005
├─ 製造單 F1150929005   領用材料欄寫著「裁切G1150929003」← 直接指向加工單
└─ 加工單 G1150929003
```

- 一張加工單**可能有、也可能沒有**對應的製造單（計畫表第 3 欄會是 `------`）
- 有對應時兩者共用同一個工令 E
- **製造單的領料欄會用文字寫出加工單號**，解析器已會抓（`parseQrp().refs`），
  這是除了工令之外的第二條線索

## 還沒確認

1. 排單表裡「機台」欄出現過 `待料`、`現場` 兩個非機台的值。建議做成狀態而不是機台，
   否則機台稼動率會被汙染。
2. 「作業總人數」是這張單的總人數，還是當班人數？跨日做的單怎麼算？
